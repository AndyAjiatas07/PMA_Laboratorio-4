Funciones en JavaScript

Las funciones son bloques de código que agrupan instrucciones para realizar tareas específicas y reutilizables dentro de un programa. Representan un concepto clave para organizar, simplificar y modularizar el código, facilitando su mantenimiento y permitiendo que ciertos procesos se ejecuten múltiples veces sin duplicar código.

2. ¿Para qué sirven las funciones?
  • Evitan la repetición de código.
  • Permiten abstraer lógica compleja.
  • Facilitan el mantenimiento y actualización del código.
  • Pueden recibir datos de entrada (argumentos) y devolver resultados (retornos).
3. Sintaxis básica de una función

Declaración de función clásica

function nombreFuncion(parámetro1, parámetro2, ...) {
  // Código que hace algo
  return resultado;  // Opcional
}

Ejemplo:

function saludar(nombre) {
  return "Hola, " + nombre + "!";
}

console.log(saludar("Andy"));  // "Hola, Andy!"
4. Partes de una función
  • Nombre: Identificador para llamar la función.
  • Parámetros: Variables que recibe la función para operar con ellas (pueden ser 0 o más).
  • Cuerpo: Bloque de código que ejecuta la función.
  • Valor de retorno: Resultado que devuelve la función con return (opcional).
5. Llamar o invocar una función

Para ejecutar la función se escribe su nombre seguido de paréntesis con argumentos si los hay: 

nombreFuncion(argumento1, argumento2);
6. Funciones sin retorno

Si no usas return, la función devuelve undefined por defecto. 

function mostrarMensaje() {
  console.log("Este es un mensaje");
}

mostrarMensaje();  // Imprime en consola
7. Funciones anónimas y expresiones de función

Una función puede no tener nombre y asignarse a una variable. 

const multiplicar = function(a, b) {
  return a * b;
};

console.log(multiplicar(3, 4));  // 12
8. Funciones flecha (arrow functions)

Introducidas en ES6, son una forma más corta de escribir funciones. 

const sumar = (a, b) => a + b;

console.log(sumar(2, 5));  // 7

Si solo hay un parámetro, se pueden omitir los paréntesis:

const cuadrado = x => x * x;

Si el cuerpo tiene más de una línea, usar llaves y return: 

const restar = (a, b) => {
  const resultado = a - b;
  return resultado;
};
9. Parámetros y argumentos

Parámetros: Variables definidas en la función.

Argumentos: Valores reales pasados cuando llamas la función.

Si no pasas argumentos, los parámetros valen undefined a menos que tengan un valor por defecto. 

function decirHola(nombre = "invitado") {
  return "Hola, " + nombre;
}

console.log(decirHola());        // Hola, invitado
console.log(decirHola("Andy"));  // Hola, Andy
10. Valores de retorno

return detiene la ejecución de la función y devuelve un valor. 

function cuadrado(x) {
  return x * x;
}

let resultado = cuadrado(5);  // 25

Si no hay return, la función devuelve undefined.

11. Funciones como objetos de primera clase

En JavaScript, las funciones son objetos, lo que significa que puedes:

  • Asignarlas a variables
  • Pasarlas como argumentos a otras funciones (callbacks)
  • Devolver funciones desde otras funciones

Ejemplo de callback:

function procesar(valor, callback) {
  let resultado = valor * 2;
  callback(resultado);
}

procesar(5, function(res) {
  console.log("Resultado: " + res);
});
12. Funciones autoejecutables (IIFE)

Se definen y ejecutan inmediatamente:

(function() {
  console.log("Función autoejecutable");
})();

Utilizadas para aislar variables y evitar contaminación global.

13. Ámbito (scope) y funciones

Las funciones crean su propio ámbito léxico. Las variables declaradas dentro solo existen ahí. 

function ejemplo() {
  let interno = 10;
  console.log(interno);  // 10
}

ejemplo();
console.log(interno);    // Error: no está definido fuera de la función
14. Funciones recursivas

Una función que se llama a sí misma para resolver un problema.

Ejemplo: Factorial

function factorial(n) {
  if (n === 0) return 1;
  return n * factorial(n - 1);
}

console.log(factorial(5));  // 120
15. Parámetros rest y operador spread

Parámetros rest: Capturan múltiples argumentos en un array. 

function sumar(...numeros) {
  return numeros.reduce((acc, val) => acc + val, 0);
}

console.log(sumar(1,2,3,4));  // 10

Spread operator: Descompone arrays o objetos en elementos individuales. 

const nums = [1, 2, 3];
console.log(...nums);  // 1 2 3
16. Hoisting en funciones

Las funciones declaradas con function nombre() son hoisted, es decir, se pueden usar antes de ser declaradas en el código. 

console.log(sumar(3,4));  // 7

function sumar(a, b) {
  return a + b;
}

En cambio, las funciones expresadas (const foo = function(){}) no se pueden usar antes de su definición.

17. Funciones async y promesas (avanzado)

Funciones que permiten trabajar con operaciones asíncronas usando async y await. 

async function obtenerDatos() {
  let respuesta = await fetch('https://api.example.com/data');
  let datos = await respuesta.json();
  return datos;
}
