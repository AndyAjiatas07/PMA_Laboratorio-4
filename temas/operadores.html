Operadores en JavaScript

Los operadores son símbolos o combinaciones de símbolos que permiten realizar operaciones sobre datos, tales como cálculos matemáticos, comparaciones entre valores o combinaciones de condiciones lógicas. Estos operadores son herramientas fundamentales que habilitan la toma de decisiones y el procesamiento de información dentro de un programa.

1. Operadores Aritméticos

Son los operadores básicos que permiten realizar operaciones matemáticas sobre números.

Operador Función Explicación Ejemplo
+Suma / ConcatenaciónSuma números o concatena strings. Si alguno es texto concatena en lugar de sumar.5 + 3 = 8 / "Hola " + "Mundo" → "Hola Mundo"
-RestaResta dos números.5 - 3 = 2
*MultiplicaciónMultiplica dos números.4 * 2 = 8
/DivisiónDivide un número entre otro.10 / 2 = 5
%MóduloDevuelve el resto de la división entera.10 % 3 = 1
**ExponenciaciónEleva el número a la potencia indicada.2 ** 3 = 8

Ejemplo práctico:

// Operadores aritméticos
let a = 7;
let b = 3;
console.log(a + b);  // 10
console.log(a % b);  // 1
console.log("Hola" + " Mundo"); // "Hola Mundo"
Calculadora simple
Resultado: 10
2. Operadores de Asignación

Se usan para asignar valores a variables. Algunos combinan la operación con la asignación.

OperadorEquivale aEjemplo
=x = yx = 5
+=x = x + yx += 3
-=x = x - yx -= 2
*=x = x * yx *= 4
/=x = x / yx /= 2
%=x = x % yx %= 3
**=x = x ** yx **= 2
 
let x = 10;
x += 5;  // Ahora x es 15
x *= 2;  // Ahora x es 30
console.log(x);  // 30
3. Operadores de Comparación

Comparan dos valores y devuelven booleanos.

OperadorExplicaciónEjemploResultado
==Igualdad con conversión"5" == 5true
===Igualdad estricta"5" === 5false
!=Diferente con conversión"5" != 6true
!==Diferente estricto"5" !== 5true
>Mayor que10 > 5true
<Menor que5 < 10true
>=Mayor o igual5 >= 5true
<=Menor o igual4 <= 2false
 
console.log(5 == "5");  // true
console.log(5 === "5"); // false
console.log(10 > 7);    // true
4. Operadores Lógicos

Combinan expresiones booleanas.

OperadorFunción
&&AND lógico
||OR lógico
!NOT lógico
 
let a = true, b = false;
console.log(a && b);  // false
console.log(a || b);  // true
console.log(!a);      // false
5. Operadores de Incremento y Decremento

Sumar o restar 1 con diferencia entre prefijo y sufijo.

let x = 5;
console.log(++x);  // 6 (prefijo)
console.log(x++);  // 6 (sufijo: muestra antes de incrementar)
console.log(x);    // 7
Incremento interactivo
Valor: 5
6. Operador Ternario

Forma corta de if-else: condición ? valorSiTrue : valorSiFalse

let edad = 20;
let mensaje = (edad >= 18) ? "Mayor de edad" : "Menor de edad";
console.log(mensaje);  // Mayor de edad
7. Operador Coma (,)

Evalúa múltiples expresiones y devuelve la última.

let x = (1 + 2, 3 + 4);
console.log(x);  // 7
8. Operadores Bit a Bit

Operan sobre los bits de enteros.

OperadorFunciónEjemploResultado
&AND bit a bit5 & 31
|OR bit a bit5 | 37
^XOR bit a bit5 ^ 36
~NOT bit a bit~5-6
<<Desplazamiento izquierda5 << 110
>>Desplazamiento derecha5 >> 12
>>>Desplazamiento derecha sin signo5 >>> 12
 
// Ejemplo bit a bit
console.log(5 & 3); // 1
console.log(5 ^ 3); // 6
9. Otros Operadores Especiales
  • typeof: Devuelve el tipo de dato. typeof 42 → "number".
  • instanceof: Verifica instancia. [] instanceof Array → true.
  • in: Comprueba propiedad en objeto. "length" in [] → true.
console.log(typeof 42);       // "number"
console.log([] instanceof Array);  // true
console.log("length" in []);  // true
10. Errores comunes y recomendaciones
  • Usa siempre === y !== para evitar coerciones inesperadas.
  • Controla tipos antes de usar + para evitar concatenación accidental.
  • Ten cuidado con prefijo y sufijo en ++ y --.
  • Los operadores bit a bit funcionan con enteros y pueden comportarse diferente con negativos.
