Condicionales en JavaScript

En JavaScript, las condicionales son estructuras de control que permiten ejecutar diferentes bloques de código dependiendo de si una condición es verdadera (true) o falsa (false). Son esenciales para la toma de decisiones dentro de un programa.

1. Conceptos Clave

Una condición es una expresión que se evalúa como verdadera (true) o falsa (false).

Se basan en operadores de comparación (==, ===, !=, <, >, <=, >=) y operadores lógicos (&&, ||, !).

Valores falsy (considerados false de forma implícita):

// Falsy values en JavaScript
false, 0, "", null, undefined, NaN

Todo lo demás se considera truthy.

2. Tipos de Condicionales en JavaScript
2.1. if

Se usa para ejecutar un bloque de código solo si la condición es verdadera.

if (condición) {
  // Código que se ejecuta si la condición es verdadera
}

Ejemplo:

let edad = 20;

if (edad >= 18) {
  console.log("Eres mayor de edad");
}

2.2. if...else

Permite ejecutar un bloque si la condición es verdadera y otro bloque si es falsa.

if (condición) {
  // Código si la condición es verdadera
} else {
  // Código si la condición es falsa
}

Ejemplo:

let esDia = false;

if (esDia) {
  console.log("Buenos días");
} else {
  console.log("Buenas noches");
}

2.3. if...else if...else

Se usa para evaluar múltiples condiciones de forma secuencial.

if (condición1) {
  // Bloque si condición1 es verdadera
} else if (condición2) {
  // Bloque si condición2 es verdadera
} else {
  // Bloque si ninguna condición es verdadera
}

Ejemplo:

let nota = 75;

if (nota >= 90) {
  console.log("Excelente");
} else if (nota >= 70) {
  console.log("Aprobado");
} else {
  console.log("Reprobado");
}

2.4. Operador ternario (?:)

Forma abreviada de escribir condicionales simples.

condición ? valorSiVerdadero : valorSiFalso;

Ejemplo:

let edad2 = 17;
let mensaje = edad2 >= 18 ? "Adulto" : "Menor";
console.log(mensaje); // "Menor"

2.5. switch

Se usa para comparar un valor contra múltiples casos posibles. Recomendado cuando se comparan muchos valores de la misma variable.

switch (expresión) {
  case valor1:
    // Código si expresión === valor1
    break;
  case valor2:
    // Código si expresión === valor2
    break;
  default:
    // Código si ningún caso coincide
}

Ejemplo:

let dia = 3;

switch (dia) {
  case 1:
    console.log("Lunes");
    break;
  case 2:
    console.log("Martes");
    break;
  case 3:
    console.log("Miércoles");
    break;
  default:
    console.log("Día no válido");
}

3. Anidación de Condicionales

Puedes colocar un condicional dentro de otro.

let edad = 25;
let licencia = true;

if (edad >= 18) {
  if (licencia) {
    console.log("Puedes conducir");
  } else {
    console.log("Necesitas licencia");
  }
} else {
  console.log("Eres menor de edad");
}

4. Buenas Prácticas
  • Evitar anidaciones profundas. Mejor separar en funciones o usar operadores lógicos.
  • Usar === en lugar de == para evitar conversiones de tipo inesperadas.
  • Operador ternario solo para condicionales simples; para lógica compleja, usar if.
  • switch es más limpio que muchos else if cuando comparas el mismo valor.
5. Ejemplo Completo
let usuario = "admin";
let clave = "1234";

if (usuario === "admin" && clave === "1234") {
  console.log("Acceso concedido");
} else if (usuario === "admin") {
  console.log("Clave incorrecta");
} else {
  console.log("Usuario no válido");
}
