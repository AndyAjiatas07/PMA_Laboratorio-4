Variables y Constantes en JavaScript

Las variables y constantes son elementos esenciales en la programación que actúan como contenedores para almacenar información. Mientras que las variables permiten que los valores cambien a lo largo del tiempo, las constantes mantienen valores fijos que no se modifican. En JavaScript, la forma de declarar y gestionar estas entidades es clave para el manejo eficiente de datos dentro de cualquier aplicación.

1. Declarar Variables en JavaScript

Para declarar variables en JavaScript se utilizan tres palabras clave:

  • var (histórica, no recomendada hoy en día).
  • let (variable con alcance de bloque).
  • const (constante con alcance de bloque, valor inmutable).
2. var — La forma antigua
var x = 10;

Características de var:

  • Tiene ámbito global o de función, no de bloque.
  • Es "hoisted": se eleva su declaración al principio del contexto (pero no su inicialización).
  • Puede causar problemas de confusión por su alcance, por eso se desaconseja usar. 
if (true) {
  var y = 20;
}
console.log(y);  // 20, porque var no respeta el ámbito de bloque
3. let — La forma moderna para variables 
let nombre = "Andy";

Características de let:

  • Tiene ámbito de bloque: solo existe dentro del bloque {} donde se declara.
  • No permite redeclaración dentro del mismo bloque.
  • Es hoisted pero en "zona muerta temporal" (TDZ), no accesible antes de la declaración. 
if (true) {
  let edad = 25;
  console.log(edad);  // 25
}
console.log(edad);    // Error: edad no está definida fuera del bloque
4. const — Declarar constantes
const PI = 3.1416;

Características de const:

  • Tiene ámbito de bloque (igual que let).
  • Debe inicializarse al momento de declarar.
  • No permite reasignación: una vez asignado el valor, no puede cambiarse.
  • No hace el valor inmutable, sólo la referencia (para objetos y arrays, las propiedades pueden cambiar). 
const edad = 30;
edad = 35;  // Error: asignación a una constante

const persona = { nombre: "Andy" };
persona.nombre = "Pedro";  // Esto sí es posible, el objeto es mutable
5. Diferencias clave entre var, let y const
Característica var let const
Ámbito Función o global Bloque Bloque
Redeclaración Permitida No permitida No permitida
Reasignación Permitida Permitida No permitida
Hoisting Sí, pero inicializa con undefined Sí, en TDZ (no accesible antes) Sí, en TDZ (no accesible antes)
Necesita inicialización No No Sí
6. Ámbito (Scope)

Las variables declaradas con let y const solo existen dentro del bloque {} donde se declararon.

var ignora el ámbito de bloque, solo respeta funciones. 

function test() {
  if (true) {
    var a = 1;
    let b = 2;
  }
  console.log(a);  // 1
  console.log(b);  // Error: b no está definida
}
test();
7. Zona Muerta Temporal (TDZ)

Las variables let y const son hoisted pero no inicializadas hasta la línea donde se declaran. Hasta ese punto, acceder a ellas genera error. 

console.log(x);  // Error ReferenceError
let x = 10;
8. Buenas prácticas
  • Usa const por defecto. Solo usa let si sabes que la variable cambiará.
  • Evita var para prevenir bugs y confusión.
  • Declara variables lo más cerca posible de donde se usan.
  • Usa nombres claros y descriptivos en camelCase.
  • Mantén la coherencia en la declaración para facilitar mantenimiento.
9. Ejemplos prácticos
Variable con let:
Contador: 0
// Variable con let
let contador = 0;
contador++;
console.log(contador);  // 1
Constante URL_API (no se puede reasignar):
const URL_API = "https://api.example.com/data";
Intentar reasignar causa error. 
// Constante
const URL_API = "https://api.example.com/data";
// URL_API = "otra url";  // Error, no se puede reasignar
Objeto constante con propiedades mutables:

Nombre actual: Andy 
// Objeto constante con propiedades mutables
const persona = { nombre: "Andy" };
persona.nombre = "Pedro";  // permitido
console.log(persona.nombre);  // Pedro
Ámbito de bloque con let:
if (true) {
  let mensaje = "Hola dentro del bloque";
  console.log(mensaje);
}
// console.log(mensaje);  // Error, fuera de alcance
