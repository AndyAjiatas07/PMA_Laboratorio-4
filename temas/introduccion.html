Introducción a JavaScript

JavaScript es un lenguaje de programación esencial en el desarrollo web moderno. Desde su creación, ha transformado la manera en que interactuamos con las páginas en internet, permitiendo que estas sean dinámicas y respondan a las acciones del usuario en tiempo real. Su historia está marcada por un crecimiento constante y una adopción masiva que ha hecho de JavaScript una pieza clave para crear experiencias digitales ricas y versátiles, desde sitios web simples hasta aplicaciones complejas que funcionan tanto en navegadores como en servidores.

1. Características principales
  • Lenguaje de tipado débil y dinámico.
  • Basado en prototipos, no en clases tradicionales (aunque desde ES6 soporta sintaxis de clases).
  • Interpretado: el navegador lo ejecuta directamente sin compilación previa.
  • Multiparadigma: permite programación imperativa, funcional y orientada a objetos.
  • Alto nivel: maneja automáticamente aspectos como la gestión de memoria.
2. Usos comunes
  • Manipular y modificar el DOM (Document Object Model).
  • Validar formularios antes de enviarlos al servidor.
  • Crear interfaces interactivas y dinámicas.
  • Consumir APIs mediante AJAX o fetch().
  • Desarrollar aplicaciones completas (Full Stack con Node.js).
3. Estructura básica

El código JavaScript puede incluirse de tres formas:

  • En línea (atributo onclick, onchange, etc.).
  • Interno (dentro de <script> en el HTML).
  • Externo (archivo .js enlazado con <script src="archivo.js"></script>).

Ejemplo básico:

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Ejemplo JavaScript</title>
</head>
<body>
  <h1 id="titulo">Hola Mundo</h1>
  <button onclick="cambiarTexto()">Cambiar texto</button>

  <script>
    function cambiarTexto() {
      document.getElementById("titulo").innerHTML = "Texto modificado con JavaScript";
    }
  </script>
</body>
</html>
4. Sintaxis básica

Variables:

var nombre = "Juan";  // Forma antigua
let edad = 25;         // Variable de alcance de bloque
const PI = 3.1416;     // Constante

Tipos de datos:

  • Primitivos: string, number, boolean, null, undefined, symbol, bigint.
  • Objetos: arrays, funciones, objetos literales, etc.

Operadores: Aritméticos (+, -, *, /, %), de asignación (=, +=, -=), de comparación (==, ===, !=, !==), lógicos (&&, ||, !).

5. Estructuras de control
let edad = 20;

if (edad >= 18) {
    console.log("Eres mayor de edad");
} else {
    console.log("Eres menor de edad");
}

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

let contador = 0;
while (contador < 3) {
    console.log("Contador: " + contador);
    contador++;
}
6. Funciones
// Declaración
function saludar(nombre) {
    return "Hola, " + nombre;
}

// Expresión
const despedir = function(nombre) {
    return "Adiós, " + nombre;
};

// Flecha (Arrow Function)
const multiplicar = (a, b) => a * b;

console.log(saludar("Ana"));
console.log(despedir("Luis"));
console.log(multiplicar(4, 5));
7. Manipulación del DOM
document.querySelector("h1").style.color = "blue";
document.querySelector("button").addEventListener("click", () => {
    alert("Botón presionado");
});
