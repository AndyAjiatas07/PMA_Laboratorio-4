Bucles en JavaScript

Los bucles son estructuras que facilitan la repetición automática de un bloque de código múltiples veces, permitiendo que tareas repetitivas se realicen de forma eficiente y sin la necesidad de escribir código redundante. Esta capacidad es fundamental para procesar colecciones de datos o ejecutar acciones hasta que se cumpla una condición específica.

1. Principios Básicos de un Bucle
  • Inicialización → Variable que controla las repeticiones (por ejemplo, let i = 0;).
  • Condición de continuación → Expresión booleana que indica si el bucle sigue o no (i < 10).
  • Actualización → Cambia el valor de la variable de control en cada iteración (i++).

Importante: Si la condición nunca se vuelve falsa, el bucle será infinito, lo que puede bloquear la ejecución del programa.

2. Tipos de Bucles en JavaScript
2.1. Bucle for – El más común

Se utiliza cuando sabemos de antemano cuántas veces debe repetirse el código. 

for (inicialización; condición; actualización) {
  // Código a ejecutar
}

Ejemplo:

for (let i = 1; i <= 5; i++) {
  console.log(`Iteración #${i}`);
}
Ventajas: Claro y compacto. Control total sobre el inicio, fin y paso de iteración.
Desventajas: No es ideal si no conocemos el número de repeticiones.
2.2. Bucle while – Ejecución condicional

Se usa cuando no sabemos cuántas iteraciones habrá y depende de una condición. 

while (condición) {
  // Código a ejecutar
}

Ejemplo:

let contador = 1;

while (contador <= 5) {
  console.log(`Contador: ${contador}`);
  contador++;
}

Características:

  • Evalúa la condición antes de ejecutar el bloque.
  • Si la condición es falsa desde el inicio, nunca se ejecuta.
2.3. Bucle do...while – Ejecución garantizada

Siempre se ejecuta al menos una vez, ya que evalúa la condición después. 

do {
  // Código a ejecutar
} while (condición);

Ejemplo:

let numero = 1;

do {
  console.log(`Número: ${numero}`);
  numero++;
} while (numero <= 5);

Uso común: cuando necesitamos mostrar un menú o solicitar datos al usuario al menos una vez.

2.4. Bucle for...in – Recorrer propiedades de un objeto

Se usa para iterar sobre las claves (propiedades) de un objeto. 

for (let clave in objeto) {
  // clave → nombre de la propiedad
}

Ejemplo:

let persona = { nombre: "Ana", edad: 25, ciudad: "Madrid" };

for (let propiedad in persona) {
  console.log(`${propiedad}: ${persona[propiedad]}`);
}

Advertencia: No se recomienda usar for...in para recorrer arrays, ya que no garantiza el orden.

2.5. Bucle for...of – Iterar valores de colecciones

Se usa para recorrer valores de elementos iterables (arrays, strings, sets, maps). 

for (let valor of iterable) {
  // valor → elemento del iterable
}

Ejemplo:

let colores = ["rojo", "verde", "azul"];

for (let color of colores) {
  console.log(color);
}
3. Control del Flujo en Bucles

JavaScript permite modificar la ejecución del bucle con:

3.1. break – Salir del bucle

Detiene completamente el bucle, aunque queden iteraciones pendientes. 

for (let i = 1; i <= 10; i++) {
  if (i === 5) break;
  console.log(i);
}
// Salida: 1, 2, 3, 4
3.2. continue – Saltar a la siguiente iteración

Ignora el resto del código en la iteración actual y pasa a la siguiente. 

for (let i = 1; i <= 5; i++) {
  if (i === 3) continue;
  console.log(i);
}
// Salida: 1, 2, 4, 5
4. Ejemplo Real – Suma de números pares
let suma = 0;

for (let i = 1; i <= 10; i++) {
  if (i % 2 !== 0) continue; // Saltar números impares
  suma += i;
}

console.log(`La suma de los pares es: ${suma}`);
// Salida: La suma de los pares es: 30
Ejecuta el ejemplo interactivo - Suma de pares de 1 a 20
5. Comparativa Rápida de Cuándo Usar Cada Bucle
Tipo de bucle Cuándo usarlo
for Cuando conocemos el número exacto de repeticiones.
while Cuando no sabemos cuántas repeticiones habrá, depende de una condición.
do...while Cuando queremos ejecutar el código al menos una vez.
for...in Para recorrer propiedades de un objeto.
for...of Para recorrer elementos de un iterable (array, string, etc.).
6. Buenas Prácticas
  • Evitar bucles infinitos (asegurar que la condición cambie).
  • Usar for...of en arrays y colecciones, no for...in.
  • Usar nombres descriptivos en variables (contador, indice, etc.).
  • Considerar métodos de arrays como forEach, map, filter para código más legible.
  • Evitar anidar muchos bucles (puede afectar el rendimiento).
7. Ejemplo Avanzado – Iterando datos complejos 
let usuarios = [
  { nombre: "Carlos", edad: 30 },
  { nombre: "Lucía", edad: 25 },
  { nombre: "Pedro", edad: 35 }
];

// Usando for...of
for (let usuario of usuarios) {
  console.log(`${usuario.nombre} tiene ${usuario.edad} años`);
}
