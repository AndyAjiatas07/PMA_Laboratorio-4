Sintaxis Básica de JavaScript

La sintaxis básica de un lenguaje de programación define cómo se estructuran y escriben las instrucciones para que la computadora las entienda. En JavaScript, esta sintaxis incluye reglas sobre cómo se deben escribir los comentarios para documentar el código, la importancia de distinguir entre letras mayúsculas y minúsculas, y el uso de signos de puntuación, como el punto y coma, para delimitar cada instrucción y mantener el orden lógico dentro del programa.

1. Comentarios

Los comentarios son líneas que el navegador ignora y que sirven para explicar el código o dejar anotaciones.

Comentario de una línea:

// Esto es un comentario de una sola línea

Comentario de varias líneas:

/*
  Esto es un comentario
  que puede ocupar varias líneas
*/
2. Declaración de Variables

En JavaScript existen tres palabras clave para declarar variables: var, let y const.

  • var: variable con alcance global o de función.
  • let: variable con alcance de bloque (recomendado para la mayoría de casos).
  • const: variable constante, no puede reasignarse.
var nombre = "Andy";   // variable vieja, evitar si es posible
let edad = 25;         // variable que puede cambiar
const PI = 3.1416;     // constante, no cambia
3. Tipos de Datos

JavaScript maneja varios tipos de datos:

  • Primitivos: number (números), string (texto), boolean (true/false), null, undefined, symbol.
  • Objetos: estructuras más complejas, como arrays, funciones, objetos literales.
let numero = 10;               // number
let texto = "Hola Mundo";      // string
let activo = true;             // boolean
let valorNulo = null;          // null
let indefinido;                // undefined
4. Operadores

Aritméticos: +, -, *, /, %
Asignación: =, +=, -=, etc.
Comparación: == (igualdad abstracta), === (igualdad estricta), !=, !==, <, >
Lógicos: && (AND), || (OR), ! (NOT) 

let x = 5;
x += 3;      // x = 8
console.log(x === 8);  // true
5. Estructuras de Control
a) Condicionales
if (edad >= 18) {
  console.log("Eres mayor de edad");
} else if (edad < 18 && edad > 0) {
  console.log("Eres menor de edad");
} else {
  console.log("Edad inválida");
}

También existe el switch para múltiples casos:

switch(dia) {
  case 1:
    console.log("Lunes");
    break;
  case 2:
    console.log("Martes");
    break;
  default:
    console.log("Otro día");
}
b) Bucles

For

for(let i = 0; i < 5; i++) {
  console.log(i);
}

While

let i = 0;
while(i < 5) {
  console.log(i);
  i++;
}

Do...while

let i = 0;
do {
  console.log(i);
  i++;
} while(i < 5);
6. Funciones

Las funciones son bloques de código reutilizables. Pueden definirse de varias formas.

Declaración tradicional:

function saludar(nombre) {
  return `Hola, ${nombre}`;
}

Función anónima asignada a variable:

const sumar = function(a, b) {
  return a + b;
};

Función flecha (más moderna):

const multiplicar = (a, b) => a * b;
7. Objetos

Los objetos agrupan propiedades y métodos.

let persona = {
  nombre: "Andy",
  edad: 25,
  saludar: function() {
    console.log(`Hola, soy ${this.nombre}`);
  }
};

persona.saludar();  // Hola, soy Andy
8. Arrays

Arreglos para almacenar colecciones de datos.

let numeros = [1, 2, 3, 4, 5];
console.log(numeros[0]); // 1

// Recorrer array
for(let num of numeros) {
  console.log(num);
}
9. Eventos

En el contexto web, JavaScript responde a eventos, como clicks o cargas.

document.getElementById("miBoton").addEventListener("click", function() {
  alert("Botón presionado");
});
10. Buenas prácticas de sintaxis
  • Usa let y const en lugar de var.
  • Usa punto y coma ; para terminar instrucciones (aunque es opcional, previene errores).
  • Nombres descriptivos y camelCase para variables y funciones.
  • Usa plantillas literales `texto ${variable}` para concatenar texto.
  • Mantén la indentación y estructura clara.
Ejemplo completo básico
// Declaración de variables
const nombre = "Andy";
let edad = 25;

// Función para verificar mayoría de edad
function esMayorDeEdad(edad) {
  if (edad >= 18) {
    return true;
  }
  return false;
}

// Uso de función
if (esMayorDeEdad(edad)) {
  console.log(`${nombre} es mayor de edad.`);
} else {
  console.log(`${nombre} es menor de edad.`);
}
