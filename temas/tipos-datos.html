Tipos de Datos en JavaScript

Los tipos de datos primitivos son las categorías fundamentales en las que se clasifican los valores básicos con los que un lenguaje de programación trabaja. En JavaScript, estos tipos representan conceptos simples como textos, números, valores lógicos y otros que permiten expresar información elemental y manejarla adecuadamente durante la ejecución de un programa.

1. Tipos Primitivos

Los tipos primitivos almacenan datos simples y son inmutables. JavaScript tiene 7 tipos primitivos:

a) Number (Números)

Representa tanto números enteros como flotantes. Internamente, JavaScript usa el estándar IEEE 754 de doble precisión para almacenar números. 

let entero = 42;
let decimal = 3.14;
let negativo = -10;

No existe un tipo separado para enteros o decimales.

Soporta valores especiales: Infinity, -Infinity, y NaN (Not a Number). 

console.log(1 / 0);       // Infinity
console.log("a" * 3);     // NaN
b) String (Cadenas de texto)

Secuencia de caracteres Unicode. Se pueden definir con comillas simples, dobles o backticks (plantillas literales). 

let saludo = "Hola";
let nombre = 'Andy';
let frase = `Hola, ${nombre}`;  // Template string

Los strings son inmutables, no puedes cambiar un carácter directamente.

c) Boolean (Booleanos)

Solo tiene dos valores posibles: true o false. Usado en lógica y control de flujo. 

let esMayor = true;
let tieneAcceso = false;
d) Undefined

Es un valor especial que indica que una variable ha sido declarada pero no inicializada. 

let x;
console.log(x);  // undefined
e) Null

Representa la ausencia intencional de cualquier valor u objeto. 

let y = null;
console.log(y);  // null

null y undefined son diferentes aunque ambos representan “nada”.

f) Symbol (Introducido en ES6)

Un valor único e inmutable usado principalmente para propiedades de objetos que no colisionen. 

let sym1 = Symbol('id');
let sym2 = Symbol('id');
console.log(sym1 === sym2);  // false, son únicos
g) BigInt (Introducido en ES2020)

Permite manejar enteros muy grandes, fuera del rango seguro de Number. 

let big = 9007199254740991n;  // Nota la "n" al final
console.log(typeof big);      // "bigint"
2. Tipos de Datos de Objeto

Los objetos pueden almacenar colecciones de datos y funcionalidades. No tienen un tamaño fijo y son mutables.

a) Object (Objeto Literal)

Colección de pares clave-valor.

let persona = {
  nombre: "Andy",
  edad: 25,
  activo: true
};

Puedes acceder o modificar propiedades:

console.log(persona.nombre);  // Andy
persona.edad = 26;
b) Array (Arreglos)

Lista ordenada de valores, indexados desde 0.

let numeros = [1, 2, 3, 4];
console.log(numeros[2]);  // 3

Arrays son objetos especiales con métodos propios (push, pop, map, filter, etc.).

c) Function (Funciones)

En JavaScript las funciones son objetos de primera clase.

function saludar() {
  console.log("Hola");
}
d) Date, RegExp, Map, Set, WeakMap, WeakSet, etc.

JavaScript también tiene tipos de objetos especializados para manejar fechas, expresiones regulares, colecciones únicas, etc. 

let fecha = new Date();
let regex = /abc/gi;
let conjunto = new Set([1, 2, 3]);
3. Tipos Dinámicos y Conversiones Implícitas

JavaScript permite cambiar el tipo de una variable en cualquier momento: 

let dato = "10";   // string
dato = 10;         // ahora number

Conversiones automáticas (coerción):

JavaScript a menudo convierte tipos automáticamente, lo que puede causar confusión: 

console.log("5" + 1);    // "51" (concatenación)
console.log("5" - 1);    // 4 (conversión a número)
4. typeof — Para identificar tipos

El operador typeof devuelve una cadena con el tipo del dato. 

typeof 42;           // "number"
typeof "texto";        // "string"
typeof true;           // "boolean"
typeof undefined;      // "undefined"
typeof null;           // "object" (bug histórico)
typeof Symbol();       // "symbol"
typeof 10n;            // "bigint"
typeof {};             // "object"
typeof [];             // "object"
typeof function(){};   // "function"

Nota importante: typeof null devuelve "object", que es un error histórico en JS.

5. Valores Falsos (Falsy values)

En contextos booleanos, estos valores se consideran false:

  • false
  • 0
  • "" (cadena vacía)
  • null
  • undefined
  • NaN

Todo lo demás es considerado true.

if (!0) console.log("0 es falso");  // se imprime
6. Inmutabilidad y Mutabilidad

Primitivos son inmutables: no puedes cambiar su valor directamente, sólo reasignar la variable.

Objetos son mutables: puedes cambiar sus propiedades o elementos. 

let a = "hola";
a[0] = "H";  // No cambia nada, strings son inmutables

let obj = {nombre: "Andy"};
obj.nombre = "Pedro";  // sí cambia
7. Ejemplos prácticos de tipos y comportamiento 
// Primitivos
let n = 10;
let s = "texto";
let b = true;
let u;
let nl = null;
let sym = Symbol("id");
let bigInt = 9007199254740991n;

// Objetos
let obj = {a: 1, b: 2};
let arr = [1, 2, 3];
let fn = function() { return "función"; };

// typeof
console.log(typeof n);       // number
console.log(typeof sym);     // symbol
console.log(typeof obj);     // object
console.log(typeof fn);      // function

// Coerción implícita
console.log("5" + 2);  // "52"
console.log("5" * 2);  // 10
